> **本地库说明：** GRE 交互数据（词汇、题目、Quant 笔记、写作）存在浏览器 **IndexedDB**（库名 `kaoyan-gre`）。今天不接远程；关页刷新不丢。换电脑前用词汇页「导出备份 JSON」。

## 三块入口

| 板块 | 做什么 | 入口 |
|------|--------|------|
| **Verbal** | 查词存释义；总览表；错题点词下标 | [添加](/gre/verbal/vocab/) · [总览](/gre/verbal/vocab-overview/) · [题目](/gre/verbal/questions/) |
| **Quantitative** | 短错题 + 知识点坑点 | [导读](/gre/quant/overview/) |
| **Writing** | 模板积累 + 完整范文 | [模板](/gre/writing/templates/) · [范文](/gre/writing/essays/) |

## Verbal 工作流（建议）

1. [添加词汇](/gre/verbal/vocab/) → 「打开 Longman 查词」→ 粘贴释义存入
2. [词汇总览](/gre/verbal/vocab-overview/) → 按字母/时间看全部，搜索后点「修改」
3. [题目页](/gre/verbal/questions/) 贴错题/难句，点单词看下标（同一词库）

## 日后部署

接口已收在 `src/lib/gre-db.ts`。上线时把 IndexedDB 换成远程 API 即可，页面交互可复用。
