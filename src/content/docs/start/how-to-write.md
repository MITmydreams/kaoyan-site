原则：**一页一事**；半年后自己能读懂；占位先留着，别编造进度。

## 知识点页（复制骨架）

```markdown
← [科目地图](/knowledge/<科目>/overview/) · 上一章 → … · 下一章 → …

## 一句话
## 考什么 / 常见坑
## 我的理解
## 例题钩子
（链到错题 ID，可先空）
## 关联教辅页
## 还没搞清的点
```

## 错题页

```markdown
## 题目来源
## 我的错因
## 正确思路
## 关联知识点
## 复习日期 / 是否已消灭
```

错因取值约定见 [错因标签说明](/wrongs/tags/)。

## 经验页

```markdown
## 情境
## 做法
## 结果
## 下次怎么改
```

## 教辅页

```markdown
## 适合谁
## 怎么用
## 章节 ↔ 本站知识点
## 我的评价
## 进度
```

## 文件命名

| 类型 | 建议 |
|------|------|
| 知识点章 | `01-slug.md`（数字前缀排序） |
| 错题 | `W-政治-001.md` 或 `YYYY-MM-DD-slug.md` |
| 打卡 | `plan/log/YYYY-MM/YYYY-MM-DD.md` |
| 教辅 | `shelf/books/<slug>.md` |

改完用 `npm run dev` 热更新预览。
