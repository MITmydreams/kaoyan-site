---

← [错题本导读](/wrongs/overview/)

录入时在「我的错因」里选 **一个主标签**（可再加半句说明）。

| 标签 | 含义 | 典型表现 |
|------|------|----------|
| 概念 | 知识点本身不会 | 公式/定义记混 |
| 审题 | 条件看漏或看错 | 忽略「充分/必要」等 |
| 方法 | 会概念但不会下手 | 不会选通法 |
| 计算 | 步骤对但算错 | 符号、积分限 |
| 粗心 | 会做却写错抄错 | 选项填反 |
| 时间 | 会但当时没做完 | 节奏问题 |
| 其他 | 以上都不贴 | 写清楚一句 |

消灭标准建议：隔一周还能独立做对，再标「已消灭」。
