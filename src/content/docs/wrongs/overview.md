## 何时录入

- 模考 / 真题 / 教辅练习里：**会再错一次的**才建页
- 纯计算笔误可只在打卡里记一句，不必开页

## 文件约定

- 路径：`wrongs/<科目>/W-<科目>-NNN.md` 或 `YYYY-MM-DD-slug.md`
- 侧栏按科目 `autogenerate`

## 单题模板（固定）

```markdown
## 题目来源
## 我的错因
## 正确思路
## 关联知识点
## 复习日期 / 是否已消灭
```

错因取值见 [错因标签说明](/wrongs/tags/)。

## 交叉链接

- 错题 → 知识点相对链接  
- 知识点「例题钩子」→ 错题  
- 本周计划只列本周要消灭的错题 ID
